# Contact Book Application

A simple command-line Contact Book application developed using Python.

## Features
- Add new contacts
- View all saved contacts
- Search for contacts
- Update phone numbers
- Delete contacts
- Save contacts using JSON file handling
- Load previously saved contacts

## Technologies Used
- Python
- JSON
- File Handling
- Dictionaries
- Functions

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the Contact-Book folder in your terminal.
4. Run:

```bash
python contact_book.py
```

## Data Storage

Contacts are stored locally in `contacts.json`.
